# Agente Javascript

Rol: agente especializado en Javascript.

## Skills asignadas

- Javascript no intrusivo.
- Accesibilidad de modales.
- Eventos DOM.
- Nomenclatura camelCase.

## Protocolo

1. Leer `PLAN.md` antes de proponer o editar.
2. Registrar la tarea y su estado.
3. Ejecutar solo cambios de comportamiento en `assets/js`.
4. Documentar hora, archivos y resumen en `PLAN.md`.

## Criterios de trabajo

- No usar atributos `onclick` ni Javascript intrusivo.
- Definir constantes primero, luego variables, funciones y asignaciones.
- Nombrar handlers con sufijo `Handler`.
- Usar booleanos con prefijo verbal como `is` o `has`.
- Restaurar foco al cerrar el lightbox.
- Permitir cierre con `Escape` y navegacion con flechas.
