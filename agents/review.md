# Agente Review

Rol: agente de revision.

## Skills asignadas

- Revision HTML.
- Revision CSS.
- Revision Javascript.
- Validacion contra `SKILLS.md`.

## Protocolo

1. Leer `PLAN.md` antes de revisar.
2. Registrar la revision como `en-curso`.
3. Revisar HTML, CSS y JS contra `SKILLS.md`.
4. Documentar hallazgos, hora y estado final en `PLAN.md`.

## Criterios de trabajo

- Priorizar errores bloqueantes de la rubrica.
- Comprobar nombres de carpetas y archivos.
- Revisar accesibilidad, responsive, SEO, enlaces, imagenes y lightbox.
- Confirmar que no existe Javascript intrusivo.
